## CN2 GIA、CN2 GT、CMI，到底差在哪

香港机房离内地近，延迟通常 40 到 60ms，美国机房 130ms 以上，日本机房 70ms 以上，这是物理距离决定的，换什么线路都改不了。真正拉开差距的是从香港回内地那一段走哪条骨干网。

香港到内地的线路大致分三档：163、CN2 GT、CN2 GIA，GIA 是里面最好的一条。严格意义上的“香港 CN2 GIA”，指电信去回程都走 CN2 GIA，移动和联通走各自的直连线路，有时候移动和联通一起借联通直连。GT 相当于普通快车，高峰期照样会波动；GIA 是高速直达，全程有 QoS 保障。

坑就在这儿：有些商家页面上写着“CN2”，实际给的是 CN2 GT 或者 163。判断办法很朴素——看它写的是“CN2 GIA”还是只写“CN2”，看它给不给测试 IP，再看价格。真正的 CN2 GIA 线路不会便宜，成本摆在那里。香港一台 2核2G、40G 硬盘、0.5TB 流量、1Gbps 端口的 CN2 GIA，市面标价是 89.99 美元一个月，折人民币六百多元。

CMI 是另一套体系，全称是中国移动国际，和电信的 CN2 不是一回事。商家页面上还会出现 AS9929、AS4837、CMIN2 这些编号，那是联通和移动的精品骨干，香港一堆“三网优化”方案就是电信走 CN2、联通走 9929、移动走 CMIN2 拼出来的。六六云香港这三档，套餐名直接标着 CMI，指移动国际入口，官网没有公开三网去回程的具体路由。它的定位是大陆方向有优化，但拿不到电信双向 CN2 GIA 那种保证。

## 这条线的短板，和三种不该买的情况

**它没有 CN2 GIA。** 电信用户晚高峰会不会抖，官网没公开路由图，我看不到答案，你只能用测试 IP 自己测。香港这个价位想拿电信双向 CN2 GIA，基本不现实。

**流量和带宽不成比例。** 150Mbps 满速跑，800GB 只够跑十二个小时出头。算给你看：800GB 是 819200MB，除以 18.75MB/s，大约 43690 秒，也就是 12.1 小时。50Mbps 那两档同理，满速跑 36 小时左右就把一个月流量吃干净。所以 150Mbps 是峰值，是突发带宽，不适合 24 小时挂着跑。做视频、下载站、给客户传大文件，这个流量撑不到月底。

**机房 IP，不是住宅 IP。** 香港的数据中心 IP 想看 TVB、解锁 Netflix 港区，这类服务认的是 IP 属性，机房 IP 通常过不了。六六云美国线上有发工单做 DNS 解锁流媒体的做法，香港这条线没看到类似说明。

三种人不该买：认准电信双向 CN2 GIA 的，比如游戏加速、对电信晚高峰极敏感的业务；要跑大流量分发的；要原生住宅 IP 做账号业务的。这三种情况，香港这个价位解决不了，换产品线或者加预算。

## 常见问题

### 香港的服务器需要备案吗

不需要。服务器在香港，域名解析过去就能上线，不走内地的备案流程。这也是不少人放着内地机房不选、转投香港的原因。

### 50Mbps 带宽够不够建站

看站有多重。文字为主的博客、企业展示站，50Mbps（6.25MB/s）够用，一个 1MB 的页面一秒能送出去六个。图片多、带视频、要给人下文件，就上 150Mbps 那档。

### 香港机房 IP 能解锁港区流媒体吗

大概率不行。港区流媒体认 IP 属性，数据中心 IP 通常过不了。要解锁得用香港住宅 IP 或者 ISP 属性的 IP，那是另一类产品，价格也不在一个档。

先把月付跑满一个月再说。香港这条线的实际表现跟你所在城市、用的运营商关系很大，别人测出来 40ms，你这边未必一样。跑顺了再考虑拉长周期。
